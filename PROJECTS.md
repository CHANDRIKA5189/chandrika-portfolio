# Project Catalog

This catalog aligns the projects presented across the CV, portfolio website and GitHub repositories.

## Healthcare AI & NLP

### AI-Powered Clinical Decision Support System
Full-stack healthcare AI system for disease prediction from user-reported symptoms. The portfolio/CV describes spaCy-based symptom extraction, Random Forest/XGBoost prediction, confidence scores, severity classification, LLM-assisted recommendations, PDF reports and voice input.

**Status:** Featured portfolio project. A dedicated source repository is not currently present in the connected GitHub repository list.

### AI Medical Question Answering System
Retrieval-based medical Q&A system using the MedQuAD dataset (47,000+ Q&A pairs), NLP entity recognition and an interactive interface.

**Repository:** `medicalchatbot`

## Computer Vision & Deep Learning

### Real-Time Drowsiness Detection System
CNN-based eye-state classification with real-time face/eye detection, age prediction and GUI monitoring. The CV reports 94% validation accuracy for the eye-state classifier, <200 ms multi-person inference latency and 88% age classification accuracy.

**Repository:** `DROWZINESS-DETECTOR`

### Age Detection System
Deep-learning age prediction project based on facial images and the UTKFace dataset.

**Repository:** `age-detector`

### Multi-Attribute Vision Intelligence System
Multi-model computer vision pipeline covering age, emotion, nationality and dress-colour prediction, with GUI/model integration components.

**Repository:** `detection`

### Nationality Detection System
Facial-image prediction system integrating nationality and emotion models with conditional age and dress-colour outputs.

**Repository:** `detection`

### Image Caption Generation
Vision-language project focused on generating natural-language descriptions from images.

**Repository:** `v0-image-caption-generation`
