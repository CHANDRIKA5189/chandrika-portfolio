# AI-Powered Clinical Decision Support System

A full-stack healthcare AI system designed to support preliminary disease-risk assessment from patient-reported symptoms and clinical text.

## Overview
The system combines natural-language processing with supervised machine learning to transform symptom descriptions into structured features and generate disease predictions with confidence and severity information.

## Key Features
- Clinical text preprocessing and NLP using spaCy
- Disease prediction using Random Forest and XGBoost
- Confidence scoring for predictions
- Severity classification
- Downloadable prediction/report workflow
- Full-stack application architecture

## Technology Stack
- Python
- spaCy
- scikit-learn
- XGBoost
- Pandas / NumPy
- Machine Learning
- Natural Language Processing

## Workflow
1. User provides symptoms or clinical text.
2. NLP preprocessing extracts useful clinical information.
3. Features are prepared for the trained prediction models.
4. Random Forest / XGBoost models generate predictions.
5. The application presents predicted disease, confidence and severity information.
6. Results can be exported as a report.

## Disclaimer
This project is an educational/research prototype and is **not a medical diagnostic device**. Predictions should not replace evaluation by a qualified healthcare professional.
