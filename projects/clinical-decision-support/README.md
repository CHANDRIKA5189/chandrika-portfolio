# AI-Powered Clinical Decision Support System

## Overview
A full-stack healthcare AI system designed to predict diseases from user-reported symptoms and present results in an accessible format.

## Capabilities
- spaCy-based NLP pipeline for symptom extraction.
- Random Forest / XGBoost disease prediction.
- Top predictions with confidence scores.
- Low / medium / high severity classification.
- LLM-based module for user-friendly recommendations.
- Downloadable PDF reports.
- Voice-based symptom input through the Web Speech API.

Healthcare AI · NLP · Machine Learning · Generative AI
