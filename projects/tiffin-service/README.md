# Tiffin Service Web Platform

## Overview
A responsive full-stack food-ordering platform designed around customer information, menu browsing, payments and order-management functionality.

## Key Features
- Responsive web interface.
- Menu and food-item presentation.
- Customer information and contact flows.
- Payment integration.
- Order-management functionality.
- Full-stack application architecture.

## Technology Stack
React / Next.js · Node.js · Express · MySQL · JavaScript · Razorpay

## Workflow
Customer → menu → order → payment → order management.

## Repository
The implementation is available in `tiffin-service`.
