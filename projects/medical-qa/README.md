# AI Medical Question Answering System

## Overview
A retrieval-based medical question-answering system built around the MedQuAD dataset and NLP techniques.

## Highlights
- Uses 47,000+ medical question-answer pairs from MedQuAD.
- NLP/entity-recognition workflow for understanding user queries.
- Retrieval-based answer generation.
- Interactive user interface for asking medical questions.

## Technology Stack
Python · NLP · MedQuAD · Information Retrieval · Entity Recognition

## Workflow
User question → NLP processing → relevant medical-content retrieval → answer presentation.

## Repository
The implementation is available in the `medicalchatbot` repository.

> **Disclaimer:** This project is for educational/research purposes and does not provide medical diagnosis or treatment.
