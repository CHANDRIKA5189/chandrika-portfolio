# Multi-Attribute Vision Intelligence System

## Overview
A multi-model computer-vision pipeline designed to infer multiple visual attributes from facial images.

## Capabilities
- Age prediction.
- Emotion prediction.
- Nationality prediction.
- Dress-colour prediction.
- GUI/model integration components.

## Technology Stack
Python · TensorFlow/Keras · Computer Vision · Deep Learning · OpenCV

## Workflow
Input image → preprocessing → attribute-specific models → predictions → integrated output.

## Repository
The implementation is represented in the `detection` repository.
