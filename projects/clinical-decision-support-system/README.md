# AI-Powered Clinical Decision Support System

## Overview
A full-stack healthcare AI system designed to support disease prediction from user-reported symptoms.

## Key Features
- Symptom extraction using spaCy-based NLP.
- Disease prediction using Random Forest and XGBoost models.
- Confidence scoring and severity classification.
- LLM-assisted recommendation workflow.
- PDF report generation.
- Voice-input support.

## Technology Stack
Python · spaCy · Scikit-learn · XGBoost · NLP · Machine Learning · LLMs

## Workflow
User symptoms → NLP symptom extraction → feature preparation → disease prediction → confidence/severity analysis → recommendation → report generation.

## Project Scope
This project demonstrates the integration of traditional machine learning, NLP and generative-AI-assisted workflows into a healthcare decision-support application.
