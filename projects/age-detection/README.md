# Age Detection System

## Overview
A deep-learning computer-vision project for predicting age from facial images using the UTKFace dataset.

## Key Features
- Facial-image preprocessing.
- Deep-learning age prediction.
- Model training and evaluation.
- Inference workflow for new facial images.

## Technology Stack
Python · TensorFlow/Keras · Computer Vision · CNN · UTKFace

## Workflow
Facial image → preprocessing → deep-learning model → predicted age.

## Repository
The implementation is available in `age-detector`.
