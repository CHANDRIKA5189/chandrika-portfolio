# Real-Time Drowsiness Detection System

## Overview
A computer-vision system for real-time monitoring of eye state and drowsiness, with additional age-prediction functionality.

## Highlights
- CNN-based eye-state classification.
- Real-time face and eye detection.
- Multi-person inference support.
- GUI-based monitoring.
- Integrated age prediction.
- Reported validation accuracy: 94% for the eye-state classifier.
- Reported multi-person inference latency: under 200 ms.
- Reported age-classification accuracy: 88%.

## Technology Stack
Python · TensorFlow/Keras · OpenCV · CNN · Computer Vision

## Workflow
Camera input → face/eye detection → eye-state classification → drowsiness monitoring → GUI alerts/visualization.
