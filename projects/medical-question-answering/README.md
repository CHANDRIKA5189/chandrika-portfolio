# AI Medical Question Answering System

An NLP-based medical question-answering application built around the MedQuAD dataset, providing an interactive interface for questions related to diseases, symptoms and treatments.

## Features
- Medical question answering using the MedQuAD dataset
- NLP preprocessing and retrieval workflow
- Interactive Streamlit interface
- Medical entity extraction
- User feedback and interaction analytics
- Analytics dashboard for query and feedback analysis

## Technology Stack
- Python
- NLP
- MedQuAD
- spaCy
- Streamlit
- TF-IDF / information retrieval
- Pandas

## Application Flow
1. User enters a medical question.
2. The question is processed and relevant information is retrieved.
3. The system returns the best available answer from the knowledge base.
4. Extracted entities and interaction information can be logged for analytics.
5. Feedback can be reviewed through the analytics dashboard.

## Disclaimer
This project is for educational and research purposes. It does not provide medical diagnosis or professional medical advice.
