# Multi-Attribute Vision Intelligence System

A real-time computer-vision pipeline designed to detect and classify multiple visual attributes from camera/video input.

## Overview
The system combines face/person detection with deep-learning classification models to analyze attributes from visual input while maintaining a low-latency inference workflow.

## Key Features
- Real-time video/image processing
- Multi-attribute visual classification
- Face/person detection
- Deep-learning inference pipeline
- Low-latency processing designed for interactive use

## Technology Stack
- Python
- TensorFlow / Keras
- OpenCV
- Computer Vision
- CNN / Deep Learning

## Workflow
1. Acquire image or video frames.
2. Detect relevant people/faces.
3. Crop and preprocess regions of interest.
4. Run attribute-specific models.
5. Aggregate predictions and display the results.

## Performance
The portfolio/CV reports a multi-person inference pipeline with latency below 200 ms.
