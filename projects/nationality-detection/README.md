# Nationality Detection System

## Overview
A computer-vision prediction system integrating nationality and emotion models with conditional age and dress-colour outputs.

## Key Features
- Facial-image preprocessing.
- Nationality prediction.
- Emotion prediction.
- Conditional age prediction.
- Dress-colour prediction.
- Integrated model output.

## Technology Stack
Python · TensorFlow/Keras · OpenCV · Deep Learning · Computer Vision

## Workflow
Face image → preprocessing → nationality/emotion inference → conditional attribute models → combined prediction output.

## Responsible AI Note
Visual inference of nationality from appearance is inherently limited and can encode dataset bias. This project should be treated as an experimental computer-vision exercise, not as a reliable method for determining a person's actual nationality or identity.
